# Apparel Visual Branding

## Objective
Prepare professional apparel product images, mockups, advertising layouts, and brand-neutralized product visuals for sales use.

## Core Editing Rule
When the user asks to replace or remove branding:
- Preserve garment construction, silhouette, fit, fabric texture, color, wash, seams, stitching, lighting, shadows, perspective, and background unless instructed otherwise.
- Remove original customer / third-party brand names, logos, proprietary graphics, and other potentially infringing brand elements when requested.
- Replace only the requested branding with the current company brand when appropriate.
- Do not introduce unrelated graphics or redesign the garment.
- Do not retain customer-specific neck labels or main labels when the user asks for a brand-neutral product image.

## Workflow
1. Inspect the reference image and identify garment structure and branding elements.
2. Separate protected / customer-specific elements from generic decorative elements.
3. Define exactly what changes and what must remain unchanged.
4. Generate or edit the image with minimal visual deviation.
5. Check logo placement, scale, material interaction, lighting, perspective, and edge quality.
6. Check that removed customer branding has not reappeared elsewhere.
7. Check that the final image does not accidentally introduce a different third-party logo or trademark.
8. For advertising layouts, preserve the approved template proportions and hierarchy when the user requests a template-based design.

## Brand Configuration
Use the current company profile for the active company name and approved brand assets. Do not hard-code YuMu into this skill.

## Rules
- Do not claim a visual edit is technically identical if the image-generation result changes garment details.
- Do not reproduce protected customer artwork unless the user is authorized to use it.
- If a reference image contains a recognizable third-party brand and the task is to create a sales image, prefer removing or replacing that branding rather than presenting it as the user's own product.
- Keep the user's requested garment design intact unless a change is explicitly requested.
