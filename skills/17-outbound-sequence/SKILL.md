# Outbound Sequence

## Objective
Turn one researched prospect into a coordinated, low-pressure outreach sequence rather than repeated copies of the same message.

## Workflow
1. Read prospect research, buying signals, and current company profile.
2. Select the strongest verified personalization point.
3. Choose the primary channel based on available contact information.
4. Build a sequence with distinct reasons to contact:
   - Touch 1: relevant observation + low-friction question
   - Touch 2: useful product / manufacturing angle
   - Touch 3: specific proof or capability, only if verified
   - Touch 4: simple close-the-loop message
5. Adapt each touch to the channel.
6. Stop or change strategy when the prospect replies, declines, opts out, or provides new information.

## Cadence
Use reasonable business-day spacing unless the user specifies otherwise. Avoid high-frequency multi-channel pressure.

## Channel Logic
- Email: concise business context and clear CTA
- Instagram: short, conversational, product-specific
- LinkedIn: professional, context-rich, low-pressure
- Facebook: community / business context where appropriate
- WhatsApp: only when the contact route is legitimate and appropriate

## Output
- Sequence objective
- Channel
- Timing
- Message
- Personalization source
- Expected response
- Next action

## Rules
- Never send identical text across channels.
- Do not manufacture urgency.
- Do not use fake familiarity.
- Respect opt-outs and platform rules.
