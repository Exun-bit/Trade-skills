# Alibaba Operations

## Objective
Improve qualified traffic and inquiry conversion for an apparel OEM/ODM Alibaba store without relying on unsupported claims or keyword stuffing.

## Workflow
1. Review the current company profile before using company-specific claims.
2. Define the target buyer and product intent for the listing: streetwear brand, private-label buyer, wholesaler, startup brand, etc.
3. Analyze the product itself: garment type, fabric, fit, construction, decoration, wash, season, target gender, and use case.
4. Build a keyword cluster:
   - Core product terms
   - Construction / material terms
   - Style terms
   - Customization / OEM / ODM terms
   - Buyer-intent terms
   Avoid irrelevant high-volume keywords.
5. Create or improve the title using the most commercially relevant terms first.
6. Improve the first-screen image and product information around buyer questions: what it is, what can be customized, MOQ if verified, and how to inquire.
7. Improve description structure:
   Product overview → customization → fabric / construction → decoration → sizing → packaging → sample / bulk process → inquiry CTA.
8. Recommend related products and internal traffic paths.
9. Review performance metrics when supplied: impressions, clicks, CTR, inquiries, favorites, conversion rate, ad spend.
10. Separate traffic problems from conversion problems. Do not assume low inquiries are caused by one factor.

## Output
Provide:
- Current problem diagnosis
- Keyword cluster
- Revised title
- Short selling points
- Description structure
- Image / infographic recommendations
- CTA
- Suggested related-product links
- Metrics to monitor
- 7-day and 30-day action plan

## Rules
- Never claim a keyword is high-volume unless current data supports it.
- Do not add unsupported MOQ, lead times, certifications, factory age, customer counts, or production capacity.
- Do not repeat the same keyword unnaturally.
- Keep product attributes technically accurate.
- If platform rules may have changed, verify current Alibaba guidance before making a policy-sensitive recommendation.
