# Sampling and Order Execution

## Objective
Reduce errors between buyer requirements, sample approval, bulk production, and shipment.

## Workflow
1. Convert the buyer's request into a production checklist.
2. Confirm artwork, measurements, fabric, color, construction, decoration, labels, trims, packaging, and quantity.
3. Track sample status:
   Request → Cost confirmation → Payment → Development → Internal check → Buyer review → Revision → Approval.
4. Before bulk production, create a pre-production confirmation covering all approved details.
5. Identify critical-to-quality points and tolerances.
6. Track production milestones and communicate only confirmed dates.
7. Before shipment, confirm quantity, inspection status, packing, shipping method, and required documents.
8. Record deviations and obtain approval before proceeding when the deviation materially affects the approved product.

## Output
When useful, produce:
- Production checklist
- Sample approval checklist
- Pre-production confirmation
- QC checkpoints
- Buyer update message
- Exception / deviation record
- Shipment checklist

## Rules
- Never treat a sample as approved unless the buyer has actually approved it.
- Never assume a revision is minor when it changes fit, construction, decoration, or commercial requirements.
- Do not invent production or shipping dates.
- Preserve the latest approved version as the controlling specification.
